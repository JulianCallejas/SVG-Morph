🚀 How to Use the 3D Export Feature

Navigate to the 3D Studio page in SVG-Morph
Upload your source and target SVG files using the drag-and-drop zones
Click Initialize 3D to create the 3D scene
Adjust 3D parameters: depth, materials, lighting, and animation settings
Click the Download button to open the export panel
Select your desired format and configure export options
Click Export 3D Model to download your file
Import the exported file into Paint 3D or your preferred 3D software
